
# TAG_MULTIPLAYER

## Clone
```bash
git clone https://github.com/AdamVignolles/TAG_MULTIPLAYER.git
cd TAG_MULTIPLAYER
```

## Verify
```bash
./script/verify.sh
```

## Install
```bash
npm install
```

## Run Client
A exécuter à la racine du projet
```bash
npm run client
```

## Run Server
A exécuter à la racine du projet
```bash
npm run server
```
