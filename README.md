
# TAG_MULTIPLAYER

## Clone
```bash
git clone https://github.com/AdamVignolles/TAG_MULTIPLAYER.git
cd TAG_MULTIPLAYER
```

## Verify
```bash
./script/verify.sh
```

## Install
```bash
npm install
```

## Run Client
```bash
npm run client
```

## Run Server
```bash
npm run server
```

## Run Client + Server
```bash
npm run dev
```
